Cinematic portfolio with WebGL canvas scenes — Nuxt 2, Pixi.js, animeJS.

## Features

- WebGL canvas scenes powered by Pixi.js
- Animated transitions with animeJS
- Work pages with live embedded projects
- Static site — fast, no server needed
- PWA support

## Tech Stack

- **Nuxt 2** (static target)
- **Pixi.js** (WebGL)
- **animeJS**
- **Stylus**
- **Vuex**

## Run Locally

```bash
npm install --legacy-peer-deps
npm run dev        # http://localhost:3000
npm run generate   # static site in dist/
```
