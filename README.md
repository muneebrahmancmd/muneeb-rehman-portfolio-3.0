# Muneeb Rehman — Portfolio

Creative developer, web designer, graphic designer and AI enthusiast from Pakistan.
Nuxt 2 + Pixi.js (WebGL) + animeJS.

```bash
npm install --legacy-peer-deps
npm run dev        # http://localhost:3000
npm run generate   # static site in dist/
```

Content lives in `assets/datas/*.json` (works, about, contact, live projects). Each project page embeds the live site.
